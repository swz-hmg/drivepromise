# 음성 명령 점검 기록

DrivePromise voice-command check record — what was verified with synthetic speech on the emulator, what is still unmeasured, and the plan fixed in advance for the senior voice test.

이 문서는 음성 명령(Pleos SpeechToText, ON_DEVICE)을 **어디까지 확인했고 무엇을 아직 재지 않았는지**를 숫자와 함께 적습니다. 판 1.3.5 기준입니다.

| 한 줄 요약 | |
|---|---|
| 확인한 것 | 합성음(기계 목소리)을 인식기에 직접 넣어 듣기 → 뜻 풀이 → 대답 경로와 ‘모르면 다시 묻기’가 동작함 |
| 아직 재지 않은 것 | **시니어 실제 목소리의 정확도** — 1차 제출 뒤, 아래 4장의 미리 정해 둔 절차로 측정 |
| 그래서 | 음성 명령은 **보조 수단**입니다. 앱의 안내는 대답이 없어도 그대로 이어집니다 |

## 1. 합성음 주입 시험

- **방법:** Mac의 한국어 합성음 3종(Eddy · Sandy · Flo)으로 24문장을 만들어 16 kHz 소리로 바꾼 뒤, 마이크 대신 Pleos 인식기에 직접 넣었습니다. 인식된 글자를 앱의 닫힌 문법으로 풀어 기대한 뜻과 비교했습니다.
- **자료:** 3 목소리 × 24문장 × 2 조건(원음 · 차량 소음을 섞은 SNR 10 dB) = 144줄. 명령 120줄, 명령이 아닌 말 24줄.
- **24문장:** 뜻 5가지(약속 상태 · 다시 들려줘 · 조용히 · 응 · 아니)마다 4문장(카드 문장 3개 + 자기 말투 문장이나 질문 뒤 대답 1개), 명령이 아닌 말 4개(“약속 시간에 늦겠다” 포함).

| 지표 | 결과 | 95% 구간 |
|---|---|---|
| 명령 정확도(기대한 뜻으로 알아들음) | 73/120 = 61% | 52~69% |
| 잘못 실행(다른 명령으로 알아들음) | 3/120 = 2.5% | 1~7% |
| 다시 묻기(모르는 말로 처리) | 44/120 = 37% | 29~46% |
| 명령이 아닌 말을 명령으로 받아들임 | 0/24 = 0% | 0~14% |

| 목소리 | 정확도 | | 뜻 | 정확도 |
|---|---|---|---|---|
| Eddy | 33/40 = 83% | | 아니 | 24/24 |
| Flo | 21/40 = 53% | | 응 | 16/24 |
| Sandy | 19/40 = 48% | | 다시 들려줘 | 14/24 |
| | | | 조용히 | 12/24 |
| | | | 약속 상태 | 7/24 |

## 2. 읽는 법과 한계

- **이 숫자는 시니어 운전자의 인식률이 아닙니다.** 표본은 사실상 기계 목소리 3개입니다. 같은 소리를 다시 넣으면 인식 글자가 24/24 같았으므로, 줄 수로 계산한 구간은 실제 불확실성보다 좁습니다.
- **놓친 47줄은 모두 인식 단계에서 글자가 달라진 경우입니다.** 카드 24문장을 글자 그대로 넣으면 문법은 24/24 맞습니다. 예: “조용히 해” → ‘저희 언니에’, “뭐라고?” → ‘뭐라도’.
- **목소리 차이가 소음 차이보다 큽니다.** 원음과 SNR 10 dB 사이에는 차이가 없었습니다(짝 비교: 원음만 맞음 5 · 소음만 맞음 8).
- **실패는 대부분 안전한 쪽입니다.** 틀린 47줄 중 44줄은 아무것도 실행하지 않고 다시 묻습니다. 잘못 실행된 3줄 중 2줄은 ‘약속’이 든 말을 쉬기 대답 ‘응’으로, 1줄은 “그래, 쉬어 가자”를 ‘아니’로 들은 경우입니다.
- 사람 목소리에서 이보다 좋을지 나쁠지는 재 보기 전에는 알 수 없습니다.

## 3. 글자 수준 점검 — 명령이 아닌 말

인식기를 거치지 않고, 명령이 아닌 일상 문장 80개를 문법에 직접 넣어 보았습니다. 일부러 까다롭게 지은 문장이라 실제 발생 비율은 아닙니다.

| 묶음 | 명령으로 받아들인 수 | 예 |
|---|---|---|
| 일상 말(명령 낱말 없음) | 0/20 | “주유소 들렀다 가자” |
| 명령 낱말이 든 일상 말 | 30/40 | “다시 전화할게” → 다시 들려줘 · “네 시에 만나기로 했어” → 응 |
| 내비·라디오 말 | 8/20 | “경로를 다시 탐색합니다” → 다시 들려줘 |

낱말을 보는 닫힌 문법은 명령 낱말이 든 일상 말을 가려내지 못합니다. 그래서 오작동을 막는 장치는 문법이 아니라 **듣는 때를 좁힌 것**입니다.

- 앱은 늘 듣지 않습니다. 운전자가 ‘말하기’ 버튼을 누른 뒤 6초, 앱이 쉬기 질문을 한 뒤 5초만 듣습니다.
- 내비 안내가 나오면 듣기를 멈추고, 듣는 동안에는 앱도 말하지 않습니다.
- 알아들어서 하는 일은 ‘마지막 문장 다시 말하기 · 약속 상태 말하기 · 안내성 말 10분 미루기 · 쉬기 대답 기록’뿐입니다. 약속 경고는 ‘조용히’ 중에도 그대로 나옵니다.

## 4. 1차 제출 뒤 — 시니어 음성 시험(미리 정해 둔 절차)

목표와 판정 규칙은 자료를 보기 전인 2026-11-09에 고정했습니다. 시험은 1차 제출 전에 하지 못해 뒤로 미뤘고, 계획은 바꾸지 않았습니다.

| 항목 | 미리 정한 값 |
|---|---|
| 참가자 | 시니어 운전자 3~5명, 한 사람 24문장(자기 말투 문장을 카드보다 먼저) |
| 명령 정확도 목표 | 카드 문장 · 원음에서 85% 이상. 구간 하한이 70% 아래면 음성 비중을 줄이고 버튼 중심으로 |
| 잘못 실행 목표 | 2% 이하. 넘으면 응·아니는 질문 직후에만 받음 |
| 명령이 아닌 말 수락 목표 | 5% 이하 |
| 문법 후보 | ‘모르면 다시 묻기’ 쪽으로만 바꾸는 후보 2개. 잘못 실행이 줄고 정확도 손실이 2%p 이하일 때만 채택 |
| 판정 | 사람 녹음만으로. 합성음 결과는 판정에 넣지 않음 |

지금 제출본의 문법은 이 시험의 기준 문법 그대로입니다(코어 스펙 S125가 확인).
