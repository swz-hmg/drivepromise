영상 속 주행은 기록된 주행을 앱의 리플레이 기능으로 빠르게 재생한 것입니다(앱 안에서 실제 차량 신호와 같은 경로로 판단·발화). 말하는 구간은 1배속 그대로, 말이 없는 구간만 빨리 감았고 그 배속을 자막 띠 오른쪽에 표시합니다.
음성 장면(7·8)의 운전자 대답은 사람 목소리 대신 시험 음성(Mac 합성음)을 Pleos 인식기에 직접 넣어 확인한 것이라 영상에서는 들리지 않습니다 — 들은 말과 뜻은 자막과 앱 화면에 표시합니다.
음성 장면(8)의 첫 ‘조용히 해’ 오인식은 녹화 그대로 둔 것입니다 — 닫힌 문법이 모르는 말을 실행하지 않고 되묻는 동작을 보여 줍니다. 합성음 기준이므로 시니어 실제 목소리의 인식률을 뜻하지 않습니다(사람 목소리 측정은 1차 제출 뒤 미리 정해 둔 절차로 진행).
소리는 녹화의 앱 음성을 한 번만 정리해 넣었습니다(녹화에 섞여 있던 약 1 ms 끊김 복원 · 70 Hz 아래와 11 kHz 위 제거 · 말 사이 잡음 제거 · 고정 음량 −16 LUFS · 최종 압축 1회) — 끊김과 이음매의 ‘치지직’·‘틱’ 소리가 나지 않습니다.
