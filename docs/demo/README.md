## 장면 구성

| # | 장면 | 보여 주는 것 |
|---|---|---|
| 0 | 제목 · 문제 · 통찰 | 시니어 운전자의 ‘자기 약속’과 그 순간의 망각(카드 3장) |
| 1 | 출발 전 계획(정차) | 내비 경로를 약속에 비추어 보고 말함 — 도착 시각과 해 지는 시각(밤에 녹화해 “지금 가도 해 진 뒤예요 … 다른 날이나 동승을 생각해요”) |
| 2 | 해 지기 전 귀가(병원 → 집, 17:16 출발) | “이대로면 5시 19분 도착, 해는 5시 22분에 져요.” → 주행 화면(주황) → 17:18 도착 → “오늘 약속 5개를 모두 지켰어요.” |
| 3 | 고속도로 대신 · 비 오는 날 조심 | 갈림길 미리 알림(“앞 갈림길은 판교IC 방면이에요. 약속대로 일반도로로 가요.”) → 고속도로 진입 → 와이퍼 = 비 → 빗길 속도 → 요약 |
| 4 | 약속 구역 | 경계 300 m 전 → 밖 → 돌아옴 → 요약 |
| 5 | 2시간마다 쉬기 — 앱이 묻고 운전자가 대답 | “두 시간째예요. 쉬어 갈까요?” → ‘띵’ 뒤 5초 듣기(재생 시계 멈춤) → “응, 쉴게요” → “좋아요. 다음 쉴 곳에서 쉬어요.” → 요약 두 줄 |
| 6 | 음성 명령 — 운전자가 묻고 앱이 대답 | ‘말하기’ → “약속 알려 줘”(“해 지기 전 귀가가 위험해요. 나머지는 지키는 중이에요.” — 밤에 세워 둔 차) · “다시 들려줘” · “조용히 해”를 ‘저희 언니에’로 잘못 들은 것은 실행하지 않고 다시 말해 달라고 함 → 다른 시험 목소리로 다시 말하자 10분 조용히(편집 없이 그대로) |
| 7 | 기술 · 마무리 | 침묵 구간·내비 양보 · 사용한 Pleos SDK 5종 + AAOS · 설계 원칙 |

영상은 앱 1.3.0으로 녹화했고, 1.3.1~1.3.6에서도 영상 속 장면의 문장·순서는 같습니다. 1.3.5부터 정차 화면에는 제목 아래 D·R·I·V·E 줄이 하나 더 있습니다(영상에는 없음)(1.3.2부터 약속 구역 ‘밖’·‘돌아옴’은 위치 2번·5초 확인 때문에 약 1초 늦음).
영상 속 주행은 기록된 주행을 앱의 리플레이 기능으로 빠르게 재생한 것입니다(앱 안에서 실제 차량 신호와 같은 경로로 판단·발화). 말하는 구간은 1배속 그대로, 말이 없는 구간만 빨리 감았고 그 배속을 화면 오른쪽에 표시합니다.
음성 장면(5·6)의 운전자 대답은 사람 목소리 대신 시험 음성(Mac 합성음)을 Pleos 인식기에 직접 넣어 확인한 것이라 영상에서는 들리지 않습니다 — 인식 결과와 뜻은 화면 오른쪽에 표시합니다.
음성 장면(6)의 첫 ‘조용히 해’ 오인식은 녹화 그대로 둔 것입니다 — 닫힌 문법이 모르는 말을 실행하지 않고 되묻는 동작을 보여 줍니다. 합성음 기준이므로 시니어 실제 목소리의 인식률을 뜻하지 않습니다(사람 목소리 측정은 1차 제출 뒤 미리 정해 둔 절차로 진행).
