# docs/demo/ — 시연 영상

| 파일 | 내용 |
|---|---|
| `drivepromise_demo.mp4` | 시연 영상(약 3분, 1920×1080, 한국어 자막) — Pleos Connect 에뮬레이터 화면과 앱 음성(Pleos TTS)을 그대로 녹화하고 장면 제목·자막만 덧붙임 |

## 장면 구성

| # | 장면 | 보여 주는 것 |
|---|---|---|
| 1 | 문제 | 시니어 운전자의 ‘자기 약속’과 그 순간의 망각 |
| 2 | 정차 화면 · 출발 전 계획 | 약속 5개 상태, 경로·출발 시한 |
| 3 | 병원 → 집(해 지기 전 귀가) | 도착 예상과 일몰 비교 → 한 문장, 주행 화면 |
| 4 | 고속도로 · 비 | 고속도로 진입 · 와이퍼 → 비 · 빗길 속도 |
| 5 | 두 시간 쉬기 | 예고 → 쉬어 가기 권유 |
| 6 | 약속 구역 | 구역 끝 → 밖 → 돌아옴 |
| 7 | 주행 끝 요약 · 기술 | 약속별 결과, 침묵 구간·내비에 물러서기, 사용한 Pleos SDK |

영상 속 주행은 기록된 주행을 앱의 리플레이 기능으로 빠르게 재생한 것입니다(앱 안에서 실제 차량 신호와 같은 경로로 판단·발화).
